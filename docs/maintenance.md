# YVRMUN Website — Maintenance Guide

This is the private reference for whoever maintains the YVRMUN
website. Not for the client. Not for the MUN team.

---

## Ownership Summary

| Piece | Owner | Notes |
|---|---|---|
| GitHub repo | You | Source of truth for all code |
| Vercel project | You | Hosts the live site |
| Domain (if any) | You or MUN team | Decide before launch |
| Google Sheet | MUN team | Owned by `yvrmun26@gmail.com` |
| Apps Script | MUN team | Runs on their quota |
| Notification email | MUN team | `yvrmun26@gmail.com` |

The MUN team owns the *data pipeline*. You own the *website*.

---

## The Two Accounts Involved

- **Your Vercel / GitHub / Codespace** — where the site lives
- **MUN team Google account** (`yvrmun26@gmail.com`) — where
  applications arrive

You never need access to their Google account. They never need
access to your Vercel or GitHub. Clean separation.
